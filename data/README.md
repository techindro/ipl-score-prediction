# data/

Place the IPL dataset here before running any notebooks or scripts.

## How to get the dataset

1. Go to [https://www.kaggle.com/datasets/nowke9/ipldata](https://www.kaggle.com/datasets/nowke9/ipldata)
2. Download `ipl_dataset.csv`
3. Place it in this `data/` folder

The file is excluded from git via `.gitignore` because it is too large to push directly.

Expected file:
```
data/
└── ipl_dataset.csv    (~9 MB, ~76,000 rows)
```
